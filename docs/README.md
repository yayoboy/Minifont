## What is Minifont?

Minifont is a powerful Python CLI tool that converts TrueType, OpenType, and Web fonts into 1-bit bitmaps optimized for Arduino and embedded systems. It features:

- **Multiple Font Sources**: Local files, Google Fonts, icon fonts
- **Rich Interactive UI**: Beautiful terminal interface with live preview
- **Multiple Export Formats**: C headers, XBM, BDF, Python arrays
- **Font Discovery**: Automatic detection of fonts in directories
- **Flexible Character Sets**: Presets and custom Unicode ranges
